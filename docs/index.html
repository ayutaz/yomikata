Yomikata

日本語同形異音語の読み分けツール

デモ

テキストを入力すると、文脈に応じた適切な読み方を予測します。

処理中...

高精度な読み分け

BERTモデルを使用して、130個の同形異音語を94%の精度で読み分けます。

文脈理解

単純な辞書引きではなく、文脈を理解して適切な読み方を判定します。

簡単な導入

Pythonパッケージ、Docker、APIとして簡単に導入できます。

使用例

from yomikata.dbert import dBert

reader = dBert()
text = "そして、畳の表は、すでに幾年前に換えられたのか分らなかった。"
result = reader.furigana(text)
# => "そして、畳の{表/おもて}は、すでに幾年前に換えられたのか分らなかった。"
